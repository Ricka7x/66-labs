What's new in v0.49.1

Fixes

  • Restoring a workspace now brings back a window for an app that is running with all its windows closed, for example Docker Desktop or an app you closed the last window of. Since 0.48.0 these windows were skipped.
  • Fixed a freeze of up to three seconds while restoring a workspace that has a missing window. The "Restoring" message now appears right away.
  • The "Couldn't open another window" message now appears only when Snapback really could not open the window by any method.
