What's new in v0.49.0

New

  • Optional confirmation for the Quit shortcut. Turn on "Confirm before quitting with the shortcut" in Settings, under Snaps, and Snapback asks before it quits. It is off by default, so nothing changes unless you turn it on.

Improvements

  • Tiled windows stay lined up when you drag the divider between them, even when the two apps have different minimum sizes.
  • When a restore has to skip saved commands and links because Snapback Pro is not active, the message now says how many were skipped.
  • A restore that cannot find one of an app's windows now reports it in the final message, instead of a separate red message that hid the result.
  • Saved links are matched to windows by the whole site name. A link to x.com no longer picks a dropbox.com window.
  • Layout Lock now ends when you switch Spaces or change your displays, so it never works from a layout that no longer applies.

Fixes

  • Fixed a possible crash when an app answered a window position or size request in an unexpected way.
  • Layout Lock now recovers if macOS turns off its mouse watcher, instead of silently stopping.
  • A frozen app can no longer hold up Layout Lock for several seconds.
  • Fixed a case where checking a terminal for a running session could hang Snapback.
  • Changing workspaces while you hold the cycle shortcut no longer cancels the cycle.
