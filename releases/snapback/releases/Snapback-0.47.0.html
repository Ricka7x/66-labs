What's new in v0.47.0

Layout Lock

  • Drag the gap between two tiled windows to resize both sides at once. The preview shows exactly where each window will land, and it stops where an app stops.
  • Your pointer turns into a resize arrow when it is over a gap you can drag, and keeps that shape for the whole drag.
  • The pointer no longer jumps to another spot when you let go.
  • The small edge handles are gone.
  • If an app is still settling after a layout is applied, Layout Lock now follows where it ended up.
  • Minimum window sizes Snapback has learned now correct themselves if an app turns out to shrink further.
  • New in Settings: turn the gap drag off to drag a window edge instead, and reset the window sizes Snapback has learned.
