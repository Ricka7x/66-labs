What's new in v0.5.0

New Features

  • implement group cycling with modifier key release preview
  • improve group preview logic to exclude active group
  • enhance status bar to display active group indicator with dynamic sizing
  • add option to show active group label in status bar and update related settings view
  • implement GroupCycleHUD for displaying group cycling options and update GroupManager to expose pendingGroupId
  • cap GroupCycleHUD at 8 rows with auto-scroll to pending group
  • warn and auto-deselect duplicate app windows at save time instead of attempting unreliable multi-window restoration

Bug Fixes

  • prevent command palette key monitor from intercepting events in other windows
  • center command palette on screen and raise toast window level above command palette and HUD
