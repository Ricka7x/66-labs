What's new in v0.46.0

Layout Lock

  • Smoother edge dragging: the preview no longer freezes while you drag, and it stays on screen until the windows have landed.
  • Snapback now remembers each app's real minimum window size, so the preview stops where the app stops.
  • The "layout changed" bar is now a small Reset and Untile pill.

Fixes

  • Your Save Workspace shortcut is no longer reset every time Snapback launches.
  • Drag to snap picks the right window on setups with displays of different heights.
  • Restoring a workspace from a wake, a link or an agent no longer quits your other apps, and a second restore can no longer start while one is running.
  • A flaky license check can no longer lock you out of Pro, and if Pro ever does lapse your custom layouts and Spaces are kept and come back when you re-activate.
  • Terminal commands in a workspace are no longer typed again into a session that is already running, and sites on country domains such as .com.mx are matched correctly.
  • Restore no longer stacks two saved windows on one window, and Snapback no longer presses close or quit menu items when it needs to open a window.
