What's new in v0.1.0

New Features

  • Add SQLite (GRDB) data layer for clipboard history: ClipboardItem model, migrations, and repository with dedup/pin/retention/search
  • Add clipboard monitoring: pasteboard classifier, disk-backed image storage, privacy/own-write filtering, and polling monitor wired into the app
  • Add menu bar shell: status item + popover with a live-updating clipboard history list, click-to-copy, pin/delete
  • Redesign as a Snapback-style floating panel with shared design tokens, add global numbered paste shortcuts (configurable master key), and full Settings
  • Fix panel centering bug, widen to match Snapback, strengthen selection highlight, and animate Settings sidebar tab transitions
  • Color-code history icons per content type (accent-derived, Snapback-style) and match Settings sidebar/window/cards precisely to Snapback's exact spec
  • Switch settings cards to native GroupBox and fix sidebar button focus-ring/hover bugs to match Snapback exactly
  • Show the real filename for image-file copies instead of a generic "Image" label, and stop the panel-hide from stepping on the next mouse click.
  • Match the search bar to Snapback's sizing, replace the mystery item-count with a clear-button/shortcut-badge, and add color-coded kind filter chips.
  • Handle videos
  • Port Snapback's exact panel enter/exit animation, add icons to the status-bar menu, and make Pin/Delete inline hover actions on rows.
  • Real Quick Look thumbnails for file previews (PDFs, docs, code, archives, etc.), matching what Finder shows.
  • Remove snippets and add colors
  • port Snapback's theme system (20 presets + picker UI) into Peggo's Appearance settings
  • replace the native OS Accessibility prompt with a custom alert
  • live Accessibility permission polling → toast notifications → excluded-apps privacy feature → onboarding
  • Remove multi file support
  • Add full-width footer bar to the panel (below both the list and preview columns) and hover state to the list items
  • Add audio support and fix bug related to testing deleting real data when ran
  • mimic Snapback about and added mock urls
  • Translucent control
  • Navigate filters with arrow keys
  • Add a Code clipboard-item kind (detection via the existing looksLikeCode heuristic, storage, paste-back, row/preview UI, filter chip, keyboard cycling) plus a migration backfilling existing history items that look like code.
  • Replace the placeholder clipboard SF Symbol with the new Peggo logo mark in both the menu bar status item and the command-palette footer's app-identity icon.
  • Add missing descriptions to setting options

Bug Fixes

  • left-alignment bug in GroupBox rows (missing VStack alignment: .leading caused centering) and remove the redundant Preview row
  • Classify copied image files (Finder/Preview Copy) as image content instead of generic file
  • list-selection highlight desync during keyboard nav, and add a Clear History control to Settings.
  • the hotkey-toggle race that made reopening the panel silently fail, which also explains the focus issue.
  • Reset search and kind filter when the panel closes instead of leaving them stuck for next time.
  • Pinned items now sort to the top, with "Pinned"/"Recent" section labels so the reorder reads as intentional.
  • File preview
  • Go back to non deprecated File thunbnail generation
  • reduce numbered paste-back shortcuts from 9 slots to 5 and repair corrupted
  • arrow-key auto-scroll (missing row .id tag) and Swift 6 weak-self capture warning in retention timer
  • prevent overlapping command palettes when toggling the hotkey rapidly
  • numbered paste-back badges show the full shortcut (e.g. "⌘1")
  • closing the clipboard history panel now resets selection back to the first item (not just search/filter), so reopening never shows a stale highlighted row.
  • paste-back now surfaces an alert (with a System Settings shortcut) when Accessibility access is missing, instead of silently failing to paste.
  • selected-row highlight in the command palette now updates immediately on theme change LazyVStack wasn't propagating the theme change into already-rendered rows, so the list is now keyed to the active theme's id to force a fresh render.
  • Toasts and add enable/disable control
  • retention sweep and clear-history now purge orphaned image/video files from disk, not just their database rows.
  • Settings toggles (Launch at Login, Notifications, excluded-app rows) now use the active theme's accent color instead of the system default.
  • Remove redundant right-click context menu from history list rows (inline pin/trash buttons already cover those actions)
  • Clear History no longer deletes pinned images/videos hidden by an active search or kind filter (it was computing the keep-set from the filtered list instead of the full history)
  • Preview pane no longer flickers placeholder-then-content on selection, and video preview now shows just a minimal play button instead of the full transport bar
  • Unify image/video/file preview styling into a shared PreviewMediaStyling component (matching card border, placeholder icon size/color) so the three preview types can't visually drift apart
  • Search field's blinking caret now uses the active theme's accent color
  • Command palette no longer silently fails to reopen after the app loses focus
  • Master Key modifier toggle buttons in Settings now respond to clicks anywhere in the button,
  • Add a caption to onboarding's shortcut row nudging users to change it if it conflicts with another app
  • Theme contrast
  • Close command palette when it loses focus while keeping state
  • Wire up the new AppIcon and MenuIcon assets, fix orphaned image/video/audio files left behind by repeat copies and single-item delete, and fix the About window's title bar not matching the body color after a theme switch.
  • Remove outline from about links
  • Set defaults
  • Toggle knob
  • Fix themes that define only a light or dark variant staying active and visually mismatched when the system appearance switches to the one they don't support. Falls back to Default
  • match selected theme icon with snapback
  • stop PeggoKit tests from leaking UserDefaults plist files
  • use effectiveAccentColor for Excluded Apps toggles, fixing the disappearing switch knob over vibrancy
