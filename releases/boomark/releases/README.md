# releases

DMGs, HTML release notes, and `appcast.xml` land here, generated by `scripts/release.sh` /
`scripts/generate-appcast.sh` (part of the `macos-release-pipeline` submodule at `../scripts`).

Empty until the first real release. These files are committed directly to this repo (matching
`snapback-web`'s approach), not stored via Git LFS or excluded, so keep an eye on repo size as
releases accumulate.
