Control Your Mac Window Layout With Snapback Pro's Command Palette

Snapback Pro adds a command palette that runs any workspace, layout, or app command from one shortcut. Type to switch contexts instead of memorizing hotkeys.

The Shortcut Overload Problem

Workspace managers and window snappers pile up keyboard shortcuts. Save this layout, restore that one, switch context, move a window to the next display. The more setups you have, the more shortcuts you have to remember.

The convenience you wanted becomes a memory test.

That is why Snapback Pro adds a command palette. One shortcut opens a box you can type into, and any Snapback command is a few keystrokes away.

What a Command Palette Does

Think of it like Raycast or Spotlight, but built specifically for controlling your window layout and workspaces.

Where you used to memorize "command-shift-3 restores my meeting layout, command-shift-7 switches to coding," you now press one global shortcut, type "meeting," and hit enter.

It covers everything Snapback can do:

  • Restore any saved workspace
  • Switch between named workspaces
  • Run a layout preset
  • Open an app that belongs to a workspace
  • Trigger a deep link ("open this project and these URLs")

You do not have to remember which key does what. You just type what you want done.

Why Combine the Two

Free Snapback already restores full layouts with one keystroke. The command palette is for when you have many setups and do not want to dedicate one muscle-memory shortcut to each one.

Keep your one or two most-used layouts on dedicated shortcuts. Route everything else through the palette. It scales to as many workspaces as you create, without filling your brain with hotkeys.

What Else Pro Adds

The palette is one piece of the Pro upgrade. It also brings:

  • Spaces to group workspaces and layouts by context, so the same shortcuts mean different things in a coding space vs a design space
  • Custom layouts for defining your own window arrangements beyond the defaults
  • Adaptive resize to scale all windows when you resize one, keeping the layout full and even
  • Deep links to restore layouts that also open projects, websites, and run commands

You can see the whole feature set on the Snapback Pro page.

Try the Palette

Snapback Pro is a one-time purchase with no subscription, and the core Snapback app stays free forever. If you have outgrown juggling shortcuts, the palette is the clearest reason to upgrade.

Free users keep everything they have today. Pro is an optional upgrade for people who live in multiple layouts and want to stop memorizing keys.

See what Pro includes or download Snapback from the homepage and start with the free version.
